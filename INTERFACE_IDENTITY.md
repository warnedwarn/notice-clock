# Notice Clock design charter

Notice Clock behaves like a public measurement station, not a dashboard or receipt console. A vertical station rail opens onto two source tickets and a circular day dial. The task then advances laterally through three unequal stations: pin the records, pull the measurement lever, and read a stamped human result. Raw JSON is never the dominant result surface.

Its journey is deliberately short: disclose the source slots only when needed, post two dated records, let any observer pull the oversized measurement control, then read a deterministic interval stamp. `CONFLICT` opens one compact correction strip below the stations; it is not a graph contribution, a repeated input grid, or a receipt box.
