# Notice Clock design charter

Notice Clock behaves like a municipal tear-off calendar. The oversized dates, physical binding rings, lead-time ruler, red masthead, and bench below the clock express elapsed time before any form control is encountered. This layout is specific to temporal notice measurement and is not a reusable dashboard skeleton.

Its journey is deliberately short: post two dated records, let any observer measure them, then read a deterministic interval. `CONFLICT` opens one correction path; it is not a graph contribution or sealing workflow.
